## 1. 看板總覽

打開網站後，主頁面預設顯示「議題看板」，有三個欄位：

| 欄位 | 意思 |
|---|---|
| **等待認領** | To Do，還沒開始的任務 |
| **處理中** | In Progress，正在進行的任務 |
| **等你確認** | Review，做完了、等你檢查驗收的任務 |

「已完成」的任務不會顯示在主頁面，統一收在頁面右上角「**已完成 (N)**」連結進去的獨立頁面，避免主頁面太擁擠。

每張任務卡片上會顯示：標題、優先級（高/中/低）、標籤（GitHub/Issue/BUG/PR）、負責人頭像縮寫、進度（若有填）。

---

## 2. 新增與編輯任務

**新增**：點右上角「**+ 新增任務**」按鈕，右側會滑出一個表單，填寫：

- **標題**（必填）
- **優先級**：高／中／低
- **欄位**：預設會放進哪一欄
- **標籤**：可複選 GitHub／Issue／BUG／PR
- **負責人**：可複選（Josh／Amy／Ken）
- **進度**：0-100 的數字，可留空
- **預計完成日期**：選填，只有甘特圖視圖會用到
- **自動執行目錄／自動執行使用的 Skill**：選填，見第 9 節

填完按「**建立**」即可。

**編輯**：直接點擊任一張任務卡片，會開啟同樣的表單，修改後按「**儲存**」。表單最下方有「**刪除**」按鈕（會先跳出確認提示，避免手滑刪錯）。

---

## 3. 移動任務（拖拉 / 手機版）

**電腦版**：直接用滑鼠把卡片拖到其他欄位放開即可。

**手機版**（螢幕較窄時自動切換）：畫面上方會出現一排可左右滑動的欄位標籤，點標籤切換目前顯示哪一欄；每張卡片上會多一個「**移動到...**」下拉選單，選你要移過去的欄位即可（不用拖拉）。

---

## 4. 標記任務為已完成

兩種方式都可以：

1. **拖放標記**（電腦版）：把卡片拖到看板最下方「**拖曳到這裡標記為已完成**」的長條上放開。
2. **手動選擇**：打開任務編輯表單，把「欄位」改選「**已完成**」，按儲存。

標記完成後，該任務會從主看板消失，改到「已完成」頁面顯示。想讓任務重新出現在看板，進「已完成」頁面點開它、把「欄位」改回其他選項即可。

---

## 5. 任務描述（Markdown）與留言

打開任務編輯表單，往下捲會看到：

**描述**：支援 Markdown 語法——可以寫標題（`#`）、清單（`-`）、表格、程式碼區塊（```` ``` ````）等。上方有「**編輯／預覽**」兩個頁籤，編輯時看原始文字，切到預覽看實際渲染後的樣子。

**留言／執行紀錄**：任務儲存過一次之後（不是新建立、還沒存檔的狀態）才會出現這兩個頁籤：
- **留言**：像留言板一樣，可以新增、編輯、刪除留言，方便記錄討論或補充說明。
- **執行紀錄**：如果這張任務用過「AI 自動執行」功能（第 9 節），這裡會顯示每一次執行的完整記錄。

---

## 6. 搜尋與篩選

Toolbar 上方有兩個圖示：

- **搜尋圖示** 🔍：點開後輸入關鍵字，會即時依「**標題**」過濾任務（不比對描述或留言內容）。清空文字或點 X 就恢復顯示全部。
- **篩選圖示**：點開跳出標籤篩選面板，可勾選多個標籤，符合任一個勾選的標籤就會顯示（等於「或」的邏輯）；篩選圖示右上角會顯示目前選了幾個標籤。

搜尋和篩選可以同時使用（先篩標籤縮小範圍，再用搜尋找特定任務）。

---

## 7. 切換視圖：看板／列表／甘特圖

Toolbar 中間有三個分頁按鈕：

- **議題看板**：預設畫面，三欄拖拉看板。
- **列表視圖**：表格形式，一列一筆任務，欄位是「標題／欄位／優先級／負責人」，會顯示**全部**任務（包含已完成的），不能拖拉，點任一列可打開編輯。
- **甘特圖**：橫軸是日期（可切換「週檢視」／「月檢視」），每一筆任務畫一條從「建立日期」到「預計完成日期」的橫條，方便看時程安排。**只有填過「預計完成日期」的任務才會出現**，沒填的不會顯示在甘特圖上。點橫條或標題可打開編輯。

三種視圖可以搭配搜尋和標籤篩選一起用。

---

## 8. 明亮／黑暗模式

Toolbar 左側有一個太陽／月亮圖示按鈕，點一下即可切換明亮/黑暗模式，全站（包含彈出視窗、已完成頁面）都會跟著變。你的選擇會記在瀏覽器裡，下次打開網站會維持上次的選擇（不會跟著電腦系統設定自動變）。

## 9. 讓 AI 幫你完成任務（Hermes 自動化執行）

這個功能可以讓 AI agent（Hermes）直接幫你把任務做完，而不只是紀錄待辦事項。

### 怎麼設定

1. 打開任務編輯表單。
2. 填「**自動執行目錄**」：填一個你電腦上真實存在的 git 專案資料夾的**絕對路徑**（例如 `/home/你的帳號/我的專案`）。
3. （選填）「**自動執行使用的 Skill**」：下拉選單選一個你想讓 AI 優先使用的技能，不選的話 AI 會自己判斷要用什麼方式處理。
4. 把「**描述**」欄位寫清楚你要它做什麼（可以用 Markdown 條列步驟）。
5. 儲存後，把這張卡片拖到（或用「移動到...」選到）「**處理中**」欄位。

### 接下來會發生什麼事

- AI 會在你填的資料夾裡，用一個**獨立、隔離的工作分身**（不會動到你原本正在用的檔案）開始動手：讀程式碼、改檔案、執行指令。
- 打開該任務的「**執行紀錄**」頁籤，可以看到 AI 正在做什麼，畫面會每 2 秒自動更新，接近即時。
- AI 做完之後，會自動把它的成果**存成一個新的分支**並推送上去（例如你的 GitHub），但**不會自動幫你開 Pull Request**——這部分需要你自己到 GitHub 網頁確認沒問題後手動開。
- 完成後卡片會自動移到「**等你確認**」欄位；如果過程中失敗（例如路徑填錯、逾時），卡片會留在原本的欄位，你可以打開執行紀錄看失敗原因。

### 使用限制

- 同一時間只會有 **1 個** AI 任務在執行，其他排隊等待（優先級高的會先執行）。
- 每次執行最長 **15 分鐘**，超過會被強制停止並視為失敗。
- 這個功能需要在**跑後端伺服器的那台電腦**上安裝好 Hermes CLI 才能使用；如果你是用 Docker 方式部署，目前這個功能還不能用。

## 10. 常見問題

**Q：我拖了任務到已完成的長條，但沒有效果？**
A：拖放標記完成只在電腦版（螢幕較寬）才會顯示，手機版請改用卡片上的「移動到...」選單。

**Q：甘特圖上看不到我剛新增的任務？**
A：甘特圖只顯示有填「預計完成日期」的任務，請打開該任務編輯表單補上這個欄位。

**Q：我設定了自動執行目錄，但拖到「處理中」後沒有反應？**
A：請確認：(1) 填的路徑真的存在且是一個 git 專案；(2) 執行後端伺服器的主機上有安裝並能正常呼叫 `hermes` 指令；(3) 目前是不是已經有另一個任務正在執行中（同一時間只能跑一個，你的任務可能正在排隊）。可以打開執行紀錄頁籤查看詳細錯誤訊息。

**Q：AI 自動執行完成後，我的程式碼改動在哪裡？**
A：在你填的目錄底下會多出一個新分支（分支名稱可在執行紀錄裡看到），且已經被推送到遠端（如果那個 repo 有設定好 remote 的話）。你需要自己到 GitHub 網頁確認內容、開 Pull Request、並自行 merge。

**Q：切換明亮/黑暗模式後，換了台電腦打開網站怎麼變回明亮模式了？**
A：這個設定是存在瀏覽器本機的（localStorage），換電腦或換瀏覽器不會同步，需要重新設定一次。
